# IPS Plumbing & Heating Services LLC Website

A modern, professional, and fully responsive website for **IPS Plumbing & Heating Services LLC**. This project features a high-impact design tailored for plumbing businesses, with focus on service visibility and customer conversion.

## 🚀 Features

- **Mobile-First Design**: Optimized for perfect display on smartphones, tablets, and desktops.
- **Service-Oriented Layout**: Clear categorization of plumbing services (Emergency Repairs, Leak Detection, Pipe Installation, Water Heaters).
- **Social Proof**: Integrated customer reviews section with verified feedback.
- **Forced Visibility Branding**: High-contrast logo and branding that stays prominent across all devices.
- **Contact Integration**: Easy-to-use contact form and "Click-to-Call" functionality.
- **Performance Optimized**: Uses efficient asset loading and standard CDNs for Font Awesome and Google Fonts.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for SEO and accessibility.
- **CSS3**: Custom styles using Flexbox and Grid for layout.
- **JavaScript**: Smooth scrolling and header transition logic.
- **Font Awesome 6**: Professional iconography.
- **Google Fonts (Inter)**: Modern, readable typography.

## 📂 Project Structure

- `index.html`: The main website structure.
- `style.css`: All styling and responsiveness rules.
- `script.js`: Interactive elements and navigation logic.

## 🔧 Installation

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. No build step or local server is required for basic viewing.
